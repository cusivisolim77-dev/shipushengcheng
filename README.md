# 一腾营养师食谱生成工具
面向营养师的本地化配餐分析工具。填写客户基础信息、健康情况、饮食与生活方式后，可生成个性化配餐分析和建议。

## 使用方法

1. 下载并用现代浏览器打开 HTML 文件。
2. 填写客户信息；也可导入问卷或干预方案导出的 JSON / HTML 文件。
3. 点击“生成分析与建议”，查看分析报告。
4. 按需导出 HTML、PDF 或方案 JSON。

填写内容会保存在当前浏览器本地，不会自动上传到云端。更换浏览器或清理浏览器数据前，请先导出并妥善保存方案文件。

## 适用范围

适用于 18 岁及以上、可正常经口进食的成年人，供营养管理与配餐参考。工具不能替代医生诊断、治疗或个体化医疗建议；存在疾病、用药或特殊营养需求时，应结合医嘱由专业人员评估。
